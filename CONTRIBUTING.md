# Contributing to PalUpdater

Thanks for helping out! Bug reports, ideas, and pull requests are all welcome.

## Reporting bugs
Open an [issue](../../issues/new/choose) using the bug report template. Include the PalUpdater
version and the contents of the built-in log viewer if possible.

## Suggesting features
Open an issue or start a [discussion](../../discussions) describing the problem you want solved.

## Pull requests
1. Fork the repo and create a branch.
2. Build with the [.NET 10 SDK](https://dotnet.microsoft.com/download): `dotnet build`
3. Keep changes focused and match the existing code style. The project intentionally uses no
   third-party NuGet packages.
4. Open a pull request describing what changed and how you tested it.
